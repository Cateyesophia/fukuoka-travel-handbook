福岡・北九州 交通票券快速對照指南

JR 北九州 Rail Pass

適用 Day 2 (小倉・門司港)、Day 3 (海之中道/南藏院)。搭乘 JR 特急與新幹線 (博多至小倉段) 節省大幅車資。

IC 卡 (Suica / ICOCA / nimoca)

福岡地下鐵、西鐵電車、昭和巴士與絕大多數便利商店皆可刷卡。可用 Apple Pay 直接加值。

太宰府・糸島巴士

太宰府可搭乘西鐵旅人電車或直達巴士；糸島二見浦可從筑前前原站轉乘昭和巴士 (也可使用 IC 卡)。

飛日本海關・入境與在地旅遊注意事項

出發前請再次確認最新海關法規與登機規定，避免受罰或被沒收物品。

1. Visit Japan Web (VJW) 線上填寫

  • 建議於出發前 3 天填寫「入境審查」與「海關申報」。
  • 填寫完畢後請將 **QR Code 截圖存入手機**，以利福岡機場通關快速掃描。
  • 若同行者為家人可一併合併申報。

2. 嚴禁攜帶肉製品與違禁品 (重罰條款)

  • **嚴禁攜帶任何含肉製品**（豬牛肉乾、肉鬆、含肉包子、含肉泡麵等）。
  • 違者最高可處 **100 萬日圓罰金或 3 年以下有期徒刑**。
  • 新鮮水果、蔬菜、植物植物種子亦不可攜帶入境。

3. 行動電源與託運行李限制

  • **行動電源/鋰電池嚴禁託運**，必須放在隨身手提行李中。
  • 行動電源本體必須有清晰容量標示 (低於 100Wh / 20,000mAh)。
  • 液體類隨身每瓶不可超過 100ml，且須放入 1 公升透明密封袋。

4. 免稅 (Tax-Free) 與消費支付

  • 同一店家同一天未稅滿 **5,000 日圓** 可辦理退稅，需出示護照正本。
  • 退稅之消耗品（藥妝、食品）在日本境內**不可拆封**使用。
  • 雖然信用卡與 IC 卡普及，但老字號名店、神社御守及公車依然只收日幣現金。
在地公共禮儀溫馨提醒
• 電車內請保持安靜，手機設為靜音模式並避免通話。
• 日本街頭垃圾桶較少，建議隨身攜帶小塑膠袋裝垃圾回飯店處理。
• 路上全面禁菸（含電子菸），請至指定吸菸區或吸菸室。
